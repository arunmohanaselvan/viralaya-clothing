# Viralaya Clothing Website

A modern static website for a clothing brand built with HTML, CSS, and JavaScript.

## Preview locally

Open the folder in a browser, or run:

```bash
python -m http.server 8000
```

Then visit http://127.0.0.1:8000/

## Publish to GitHub Pages

1. Create a GitHub repository and push these files to it:
   - index.html
   - styles.css
   - script.js
2. Open the repository on GitHub.
3. Go to Settings → Pages.
4. Under Source, select the main branch.
5. Save and wait a few minutes.
6. Your site will be available at:
   https://<your-username>.github.io/<repository-name>/

## Project structure

- index.html - main page content
- styles.css - visual styling and responsive layout
- script.js - small interactions like the mobile menu and footer year
